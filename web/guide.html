1 ・ 低リチャードソン数(層の安定さとシアー)

シアー過多の層

VWSのある層で、気温が高さとともに急に下がっているほど(1000ftあたり3°Cに近いほど)揺れやすい。逆転層や圏界面より上は揺れにくい。

補足

  • 見るのは「寒気」そのものより「気温の下がり方」。上に寒気が入っても、下に暖気が入っても、下がり方が急になれば揺れやすくなります。
  • シアーが十分強ければ、寒気がなくても揺れます。ジェット気流の中心のすぐ上と下は、安定さが普通でもシアーが強いので、この要素が大きくなります。
  • 圏界面より上は揺れを止める側。成層圏は非常に安定です。CATが圏界面のすぐ下に多く、越えると収まりやすいのはこのためです。

天気図での見つけ方

  • 断面図(三十分大気解析など)で、等風速線が上下に詰まっている所(シアーが強い)と、等温線の間隔が上下に広い所(気温の下がり方が急)が重なる所。
  • ジェット軸の高さの±2,000ft、圏界面が段差になる所の近く、上層前線の中。
  • エマグラムで、1000ftあたり2.5〜3°C下がる層に、風の大きな変化が重なる所。
数式(参考)

安定度 N² = (g / θ) × (層の上と下の温位の差 ÷ 層の厚さ)
シアー S² = (上下の風の差 ÷ 層の厚さ)²(東西・南北の成分の和)
リチャードソン数 Ri = N² ÷ S²
地図の指数 = 0.75 ÷ Ri(Ri 0.75で「並」= 1.0)

温位θ = T × (1000/p)^0.286。層は、MSMの隣り合う2つの気圧面のあいだ(厚さ1.5〜2km)です。

2 ・ 変形場(Ellrod TI1)

流れの変形×シアー

上空で2つの流れが合わさってジェットになる所や、気圧の鞍部では、シアーがこれから強まって揺れやすくなる。

補足

  • 変形そのものは揺れではありません。「今は弱いが、数時間後に強まる揺れ」の予告です。前後の時刻の地図も見比べてください。
  • シアーがないと値は出ません。この地図の値(TI1)は「変形 × VWS」なので、VWSがほぼない所では、変形が強くても小さくなります。
  • 向きによっては逆に働きます。等温線を引き離す向きの変形では、温度差はかえって弱まります。このとき、この要素は揺れを大きめに見積もります。
  • 「温度変化」と言い換えるのは、少しずれています。温度差を詰めるのは変形の結果で、温度差がない所でも、この値は出ます。
  • この地図の総合での扱い:変形場は独立した揺れの原因ではないので、単独の評価は半分にしています。代わりに、シアー過多の層(低Ri)を強める補正として使います(最大1.5倍。モデル自身のシアーが強い所では、補う必要がないので弱めます)。変形が強い所では、前線帯がモデルの細かさより鋭くなり、モデルのRiは実際より大きめ(安定側)に出るためです。変形場とRiの低さが重なる所ほど、評価が高くなります。

数値の目安

「並」(TI1 = 8×10⁻⁷/s²)は、たとえば VWS 6kt/1000ftのとき、100kmあたり約15ktの風の変形(合流・引き伸ばしによる風の食い違い)にあたります。VWSが大きいほど、少ない変形で「並」になります。

天気図での見つけ方

  • 300・250hPaで、等高度線の間隔がだんだん狭くなり、1本にまとまっていく所(ジェットの入口)。
  • 2つの高気圧と2つの低気圧にはさまれた鞍部。
  • 等温線がジェットのそばに詰まり始めている所(上層前線ができつつある所)。
数式(参考)

伸長変形 DST = (東西の風の東西方向の変化) − (南北の風の南北方向の変化)
シアー変形 DSH = (南北の風の東西方向の変化) + (東西の風の南北方向の変化)
全変形 DEF = √(DST² + DSH²)
TI1 = VWS × DEF / 地図の指数 = TI1 ÷ 8×10⁻⁷(「並」= 1.0)

Ellrod(1992)の乱気流指数TI1と同じ定義です。風は層の上下の面の平均。

3 ・ 慣性不安定(負の絶対渦度)

強い高気圧性シアー

ジェット気流の南側で、南へ行くほど風が急に弱まる所は、雲がなくても揺れやすい。鋭い気圧の尾根の頂上付近も同じ。

補足

  • 「低渦度域」ではありません。条件は、高気圧性の回転(負の相対渦度)が、地球の自転の回転(f)を打ち消すほど強いこと、つまり絶対渦度がマイナスになることです。多少の高気圧性回転はどこにでもあり、慣性不安定ではありません。
  • 南ほど起きやすい。地球の自転の回転は低緯度ほど小さいので、同じ風速の差でも、南ほど不安定になります。
  • 気圧の尾根の頂上と、積乱雲の吹き出しでも起きます。流れが時計回りに強く曲がる所では、風速の差が小さくても起きます。発達した積乱雲の上から噴き出す流れ(かなとこ雲)の周りも同じです。
  • 単独では弱め。慣性不安定は、空気を横にずらす遅い動きです。その動きでシアーが強まったり、波が砕けたりして、初めて揺れになります。シアー過多の層と重なると、強く揺れやすくなります。

風がまっすぐ東西に吹き、南北の風速の差だけで回転している場合の目安です。流れが時計回りに曲がっていると、もっと小さい風速の差でも同じ状態になります。「弱」は絶対渦度がちょうど0、「並」は地球の自転の回転を25%上回る高気圧性回転です。

天気図での見つけ方

  • 250・300hPa(AUPQ35など)で、ジェット軸の南側の等風速線が詰まっている所。上の表の落ち方より急なら要注意。
  • 北へ強く張り出した、鋭い気圧の尾根の頂上付近。
  • 発達した積乱雲の上空と、その風下側(かなとこ雲の吹き出し)。
  • FXFE502(500hPa)では、網掛けのない側で、渦度が上の表の値を下回る所。ただし、500hPaの図では上空(FL300〜390)の状況はわからず、平滑化もされているので、実際には250・300hPaの風速分布で探すほうが確実です。
数式(参考)

相対渦度 ζ = (南北の風の東西方向の変化) − (東西の風の南北方向の変化)
地球の自転の渦度 f = 2Ω sin(緯度)
絶対渦度 η = f + ζ → η < 0 で慣性不安定
地図の指数 = (0.25 − η/f) ÷ 0.5(η/f = 0で「弱」0.5、−0.25で「並」1.0)

本来は、等温位面の上で見た絶対渦度(ポテンシャル渦度の符号)で判定するのがより厳密です。この地図は、気圧面の上での簡易な判定です。

注意

この地図での限界

  • 計算はMSMの隣り合う2つの気圧面のあいだ(厚さ1.5〜2km)ごとです。層の中の薄い強いシアーは平均されて弱めに出るので、シアー過多の層の目安は、理論値(Ri 0.25)より甘め(Ri 0.75)にしています。
  • 水平は約10kmの格子をさらに約15〜20kmなめらかにしているので、ジェット南側の細い帯状の強いシアーは弱めに出ます。強い高気圧性シアーと流れの変形は、実際より小さめに出る傾向があります。
  • FL060より下では、慣性不安定と変形場を評価しません(FL060〜120で徐々に効かせます)。地表に近い層では、摩擦や地形のために水平の風の差が大きく出て、これらの指標の意味が薄くなるためです。低い高度は、シアー過多の層・大気の波・地表付近の乱れ(地上風×地形)で評価します。
  • 値は予報から計算した、乱れやすい環境の目安です。乱気流そのものの予報ではなく、気象庁の航空気象情報の代わりにはなりません。
