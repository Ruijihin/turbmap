# 計算方法とデータ形式

## 入力

- 気象庁 MSM の気圧面データ(1つの初期値につき1ファイル、予報33時間分、3時間ごと)
- 格子:経度0.125度 × 緯度0.1度。使う範囲は北緯22.4〜46度、東経120〜147度(217×237マス)
- MSMの FT=0(初期値)は鉛直流がゼロなので、FT=3〜33 の11時刻を計算します

## 層

上下2つの気圧面のあいだを1つの層として計算します。

| 層 | 気圧面 | 中央の高度 |
|---|---|---|
| 1 | 700–600hPa | FL119 |
| 2 | 600–500hPa | FL161 |
| 3 | 500–400hPa | FL210 |
| 4 | 400–300hPa | FL269 |
| 5 | 300–250hPa | FL321 |
| 6 | 250–200hPa | FL363 |
| 7 | 200–150hPa | FL415 |

中央の高度は、2面の気圧の対数平均を標準大気の気圧高度に換算したものです。
画面で選んだFLの値は、上下2つの層の値を直線で補間して出します。

## 要素と「並」の目安

各要素の値を目安で割り、「並=1.0」の強さの指数にします。

| 要素 | 計算 | 並の目安 |
|---|---|---|
| 山岳波・重力波 | 鉛直流(m/s)から約60kmより大きい動きを除いた揺らぎの、5マス四方の標準偏差 σw | 0.25 m/s |
| 慣性不安定 | 絶対渦度/f。0.25のとき0、−0.25のとき1になるよう変換 | −0.25 |
| 変形場 | Ellrod TI1 = VWS × 変形(10⁻⁷ s⁻²) | 8 |
| 低リチャードソン数 | 0.75 ÷ Ri(Ri = N² ÷ シアー²) | Ri 0.75 |
| VWS(参考表示) | 上下の風の差 ÷ 層の厚さ(kt/1000ft)。色には混ぜず、総合の割り引き・上乗せの条件に使う。低RiとTI1の式にも含まれる | 6 |
| 氷相対湿度 | 層の平均の相対湿度を氷に対する値に換算(雲の目安)。**MSMの湿度が実データなのは300hPaまで。250hPa以上の層(中央FL321以上)は欠測として値255を入れ、画面では「データなし」にする** | — |

風・気温・高度には、計算前に約15kmの平滑化をかけています。

## 総合の揺れやすさ(ブラウザで計算)

1. **割り引く**
   - 低Ri:シアーが弱いとき、VWS指数/0.6 倍(最小0.3倍)
   - 慣性不安定:低Ri指数が0.5未満かつVWS指数が0.5未満のとき0.5倍
   - 変形場:VWS指数が0.3未満のとき0.6倍
2. **土台**:割り引いた4要素のうち最大のもの + 2番目×0.2
3. **上乗せ**(2つとも0.6以上などの条件を満たすとき。弱い方 × 係数)
   - 低Ri × VWS:0.35
   - 山岳波 × 低Ri:0.4
   - 慣性不安定 × 低Ri:0.25
   - 変形場 × VWS(VWS指数0.4以上):0.2
4. 区切り:0.5 弱、0.8 並、1.2 並〜強、1.6 強

係数は、解説資料の「強め合う・打ち消し合う組み合わせ」を数値にした仮の値です。

## 出力データ

R2 のバケット(画面からは `/data/` 以下)に次の形で置きます。

```
index.json                    一覧(新しい順)
runs/2026102009/meta.json     初期値ごとの情報
runs/2026102009/ft03.png      FT=3 の数値データ
runs/2026102009/ft06.png      …(FT=33 まで11個)
```

### index.json
```json
{"version":1,"updated":"2026-10-20T16:13Z","retention_days":60,
 "runs":[{"init":"2026102009","init_iso":"2026-10-20T09:00Z","ft":[3,6,…],"valid":["2026-10-20T12:00Z",…]}]}
```

### meta.json の主な項目
| 項目 | 内容 |
|---|---|
| `ft`, `valid` | 予報時間と対象時刻(UTC) |
| `files` | 予報時刻ごとのファイル名 |
| `layers`, `mid_fl` | 層の気圧面と中央の高度 |
| `lat0`, `lon0`, `dlat`, `dlon`, `ny`, `nx` | 格子。`lat0` は北端で `dlat` は負 |
| `elems` | 要素の並び `["mw","ii","df","ri","vws","rhi"]` |
| `scale`, `missing` | 0.01(画素値×0.01 が指数)。画素値255は「データなし」(氷相対湿度の上空の層) |
| `rhi_valid_max_fl`, `rhi_valid_layers` | 氷相対湿度が使える上限(FL301)と層の数(4) |
| `thresholds` | 計算に使った「並」の目安 |

### ftXX.png
- 8ビットのグレースケールPNG(幅4096)。画像ではなく数値の入れ物です。
- 画素を左上から順に読むと、`[層][要素][緯度(北→南)][経度(西→東)]` の順に並んでいます(末尾は0で埋めています)。
- 値は指数×100(0〜255)。2.55以上は255に切りそろえています。
- 位置 `(層 l, 要素 e, 行 j, 列 i)` の値は、`((l*要素数 + e)*ny + j)*nx + i` 番目の画素です。

## 3D表示と鉛直断面(ブラウザで計算)

どちらも、バッチが作った数値データ(7層)から、ブラウザ内で作ります。バッチやR2のデータは変わりません。

- **体積データ**:FL120〜FL410を10(1000ft)刻みの30段に、層の値を直線で補間します。各段・各マスで、総合(または選んだ1要素)の値を計算します。約217×237×30=約150万個です。
- **3D表示**:three.js のボリュームレンダリング(レイマーチング)です。値がしきい値(既定0.8=並)以上の領域を、半透明の塊で描きます。色は2D地図と同じです。
  - 高さの強調(既定40倍)、表示する高度の範囲、しきい値、濃さを画面で変えられます。
  - 水平は約3,000km、高さは約9kmなので、高さを強調しないと平らな板に見えます。
  - 地形の高さは使っていません。地面は平らな板に海岸線を描いています。
- **鉛直断面**:2D地図で点を2〜8点クリックし、点を結んだ折れ線に沿って約8km間隔でサンプルします。各サンプル点の値を、水平は双一次補間、高さ方向は10刻みの値の補間で求め、横軸が距離、縦軸がFLの図にします。
  - 断面に描けるのは、揺れやすさの要素の値だけです。風や気温は、バッチのデータに含まれないので描けません(前線の傾きを等温線で見たい場合は、バッチのデータに気温・風を追加する必要があります)。
  - 元データは7層なので、縦方向の細かい構造は出ません。
