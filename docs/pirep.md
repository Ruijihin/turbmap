# 揺れの報告を地図に重ねる(任意)

Googleフォームで揺れの報告を集め、地図上に三角の印で重ねます。
判定の目安や係数が実際の揺れに合っているかを確かめるのに使います。

## 設定

1. Google ドライブで新しいスプレッドシートを作ります。
2. **拡張機能 → Apps Script** を開き、`gas/Code.gs` の内容を貼り付けて保存します。
3. 関数 `setup` を選んで実行します。初回は権限の確認が出るので許可します。
   フォームが作られ、回答がこのスプレッドシートに入るようになります。実行ログに回答用URLが出ます。
4. **デプロイ → 新しいデプロイ → 種類:ウェブアプリ**
   - 次のユーザーとして実行:自分
   - アクセスできるユーザー:全員
5. 表示されたウェブアプリのURLを、`web/config.js` の `pirepUrl` に書いて、`npx wrangler deploy` します。

## 表示のルール

- 地図で選んでいる対象時刻の **前後90分**、選んでいる高度の **上下4,000ft** の報告だけを表示します。
- 色:緑=LGT、橙=MOD、赤=SEV。
- 過去7日分を返します(`Code.gs` の `DAYS` で変更)。

## 注意

- ウェブアプリのURLは誰でも読めます。便名や個人名など、公開されて困る内容は報告に入れないでください。
  入れる必要がある場合は、`doGet` で返す項目を減らしてください。
- 報告の日時は、スプレッドシートのタイムゾーン(日本時間)で解釈されます。
  スプレッドシートの **ファイル → 設定 → タイムゾーン** が「(GMT+09:00) 東京」になっているか確かめてください。
